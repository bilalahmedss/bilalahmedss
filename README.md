## 🧪 Selected Projects

### [Invoice Approval API](https://github.com/bilalahmedss/invoice-approval-api)

A multi-tenant invoice-approval API where subcontractors upload invoice PDFs and general contractors approve or reject them. Company isolation is enforced in PostgreSQL with row-level security, every decision is written to an append-only audit log by a database trigger, and the build includes a security review of its own top risks.

**Key areas:** Node.js, Express, PostgreSQL, row-level security, audit logging, threat modelling, CI

### [Prompt Injection & MCP Security](https://github.com/bilalahmedss/Prompt-Injection-MCP-Security)

A research project evaluating prompt-injection and Model Context Protocol attacks across multiple LLM-agent defence configurations.

**Key areas:** LLM security, LangChain, FastMCP, prompt injection, tool poisoning, tool shadowing, cryptographic provenance

### [BidIntel AI](https://github.com/bilalahmedss/BidIntel-AI)

A full-stack RFP analysis and bid-decision platform that extracts evaluation criteria, identifies commercial risks, evaluates draft responses, and provides grounded AI assistance.

**Key areas:** FastAPI, React, TypeScript, RAG, LlamaIndex, ChromaDB, BM25, hybrid retrieval, AI security

### AI-Driven Executive Chat and Reporting Portal (final-year project)

A full-stack conversational AI platform enabling non-technical users to query organizational data using natural language and generate structured reports. The AI service generates SQL but never executes it; a gateway enforces authentication and role-based access before running any query.

**Key areas:** Generative AI, LangGraph, FastAPI, PostgreSQL, JWT authentication, RBAC, secure SQL execution

### [Secure Payment Architecture & Threat Model](https://github.com/bilalahmedss/secure-payment-architecture-threat-model)

A STRIDE-based threat model and defence-in-depth architecture for a multi-tenant online payment-processing platform.

**Key areas:** Threat modelling, STRIDE, security architecture, IAM, network segmentation, risk treatment

### [NexusPortal: Build and Break Secure Application Pipeline](https://github.com/bilalahmedss/Build-and-Break-Secure-Application-Pipeline)

A role-based project-management application that was built, scanned, manually tested, fixed and retested to show security across the development lifecycle.

**Key areas:** Flask, PostgreSQL, Docker, RBAC, audit logging, Bandit, Semgrep, pip-audit, OWASP ZAP

### [Application Security Testing](https://github.com/bilalahmedss/Application-Security-Testing)

A hands-on application-security lab covering common web vulnerabilities, exploitation techniques, remediation controls, and OWASP Top 10 mapping.

**Key areas:** Application security, DVWA, SQL injection, XSS, CSRF, Burp Suite, Docker

### [Microsoft 365 Admin Playbook](https://github.com/bilalahmedss/m365-admin-playbook)

A personal playbook of PowerShell and Microsoft Graph scripts for Microsoft 365 administration.

**Key areas:** Microsoft 365, Entra ID, PowerShell, Microsoft Graph
